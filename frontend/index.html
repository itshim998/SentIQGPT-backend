Privacy, data & support

How data is handled

SentIQ Chat is an AI assistant for chat, file analysis, web-assisted research, and generated artifacts. Review important outputs before relying on them.

Guest chats are sent to the backend when you use chat features, but they are not saved as cloud conversations or memories. A recovery draft may remain in this browser tab if a response is interrupted.

When you sign in, conversations, messages, memories, and generated artifacts can be stored in your account. This browser also keeps a local cache so recent work remains available.

Uploaded source files are processed for analysis. The latest temporary extraction may remain in the backend session cache for up to about one hour. Relevant context can be processed by configured AI and search services when you use those features.

Terms of use

Use SentIQ Chat lawfully and review important outputs before relying on them. Do not upload data you are not authorized to process. Generated and analyzed content can contain mistakes.

Data controls

Clearing local data removes this browser's SentIQ Chat cache and temporary upload session without signing you out. Cloud conversations and memories remain until you remove them from their respective controls.

Remove cloud conversations from the sidebar and memories from Memory Manager. Generated artifacts include their own Remove action. For account-deletion help, contact support.
